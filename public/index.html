    Add a font

    Any ordinary font (TTF/OTF) can be extruded into 3D letters: one STL per letter in the cache, plus one STL with all of them.

      Or simply drop .ttf/.otf files (zipped is fine) into the assets folder or the project's fonts folder and press Rescan.
      Find font by sample

      Pick one or more STL (or 3MF) files, each holding a single letter. They are compared with the same letter in every installed system font and every 3D font in the library. Select a result to see it large beside your samples.
